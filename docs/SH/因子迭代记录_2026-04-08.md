# 因子迭代记录 2026-04-08

本文档记录 2026-04-08 这一天围绕 `src/gen` 因子生成链路、`scripts/validate_factor_effectiveness.py` 验证脚本以及 `docs/SH/*` 文档所做的连续迭代。目标是把“今天到底改了什么、为什么这么改、每一步验证得出了什么结论、当前停在什么状态”完整沉淀下来，方便后续继续扩因子、裁剪因子或为 VP-VAE 策略做分层输入。

---

## 1. 今日工作的核心目标

今天的调整主要围绕 5 条主线展开：

1. 补充高频盘口微观结构因子，而不只依赖原来的 K 线因子。
2. 将滚动窗口从单一 `60` 扩展到 `60 / 180 / 360`，观察不同时间尺度的最优因子。
3. 将 `total_trade_volume / turnover / open_interest` 作为快照字段接入，并明确“先差分、再滚动”的处理口径。
4. 将验证结果从单一 horizon 扩展为多 horizon，并最终映射到短线 / 中线 / 长线策略。
5. 在最终阶段补充“双边差分”和“流动性韧性”两类因子，使盘口结构不对称和恢复能力也进入候选池。

## 4. 今日 validate 逻辑上的重要变化

除了因子本身，今天 validate 也发生了几次关键升级。

### 4.1 从单 horizon 到多 horizon

当前默认：

- `--horizons 5,30,70`
- `--primary-horizon 5`

### 4.2 从“固定 15”回到“按类别保底 + 类别上限 + 不强制总数”

现在默认不是必须输出固定数量，而是：

- 每类至少保留一定数量
- 每类最多不超过上限
- 总体不再强制卡死在某个固定 N

这样更适合 VP-VAE 后面聚合成不同周期策略，因为：

- 只要因子清晰且不冗余，就可以保留
- 不会因为硬凑数量，把弱因子也塞进去

### 4.3 输出三套策略文件

当前 validate 会直接输出：

- `vp_vae_short_feature_list.*`
- `vp_vae_mid_feature_list.*`
- `vp_vae_long_feature_list.*`

对应：

- `short = horizon 5`
- `mid = horizon 30`
- `long = horizon 70`
